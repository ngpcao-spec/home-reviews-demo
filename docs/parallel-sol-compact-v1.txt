Experimental JEV -> Sol transport: jls-direct4-compact-sol-v1

Scope: future app experimental preparations only. The parallel protocol keeps
its existing execution/storage version and adds configuration.sol_wire_version,
which is included in its configuration/protocol hashes and future consent.
Previously sealed protocols without this field retain the exact old request
and response format. Unsupported versions fail closed. Classification inputs,
JEV configuration/cache identity, native choices, selector and statistics are
unchanged. The commercial Sol-only pipeline and UI are unchanged.

Each selected full frozen analysis text appears once in packet.reviews with a
short r-reference. Only a strictly different original is included alongside it,
with available analysis/original languages and translation source. Equality is
exact, not normalized; no new translation is performed. Distinct reviews are
never merged because their contents happen to match. Every existing association
is retained separately under an e-reference, category, polarity and r-reference.
Reference allocation sorts immutable review IDs and evidence IDs, independently
of JSONB or input ordering. The current selector's complete-review quotation is
required; a future partial quotation is blocked rather than silently expanded.

UUIDs, long evidence IDs, SHA256s, character positions, source provenance and the
complete binding manifest remain in immutable server artifacts. The manifest
binds organization, establishment, frozen snapshot, statistics and all evidence.
The sealed request and token certificate use the exact compact wire. The worker
checks that manifest/packet against its actual immutable protocol and sources
before the existing atomic one-call reservation. No retry, timeout, supplier,
consent, RLS or database procedure is altered. No migration is required.

The compact strict response schema asks for e-references and observation prose,
not copied quotations, hashes or statistical fingerprints. Before the existing
validator, the server resolves each reference in the current job's manifest,
checks review/category/polarity compatibility, and reconstructs exact frozen
quotations, hashes and long IDs. Unknown/incompatible references fail; there is
no guessed replacement. Existing reference-only derivation and source/count
validation then run normally. The raw compact response remains in the supplier
receipt; compact_response and source_reconstruction provenance are also saved
in the validated result. original_report in this path is the reconstructed
schema-compatible original, not an additional Sol response. Generated prose is
never rewritten by this transport conversion. The UI still consumes the same
expanded report structure and shows all existing history.

The shorter prompt retains source fidelity, mixed opinions, later resolution,
dominant corpus sentiment, precise isolated complaints, incident-vs-category
frequency, proportional priorities/actions and no invented cause/responsibility.
Customer texts remain untrusted data. Statistics remain automatic JEV counts,
not validated by Sol or human reference data. There is no Luna call here.
Model gpt-6.1-sol, reasoning low, output reserve 9,500, input budget 32,768 and
12% + 256 token margin remain unchanged.
