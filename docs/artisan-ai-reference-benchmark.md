Les 32 textes anglais et les 32 préannotations de `analysis_negative_validation_ai_preannotations` sont vérifiés côté serveur (IDs, SHA256, 25 choix et langue). La référence est **IA ChatGPT**, jamais un Gold humain. Aucun état humain draft/completed et aucune annotation humaine ne sont exigés. Les labels uncertain sont exclus des métriques.

Les tables existantes `analysis_negative_ai_exploratory_runs`, `analysis_negative_ai_exploratory_tasks`, `analysis_negative_ai_exploratory_results` sont réutilisées. Aucune copie n’est faite dans les tables Gold ou labels humains. Un snapshot anglais et un snapshot de la référence IA sont figés dans le run lors du clic confirmé, avec hashes et provenance. Une contrainte unique sur l’expérience et un verrou transactionnel empêchent un deuxième lancement. Les questions et seuils sont importés depuis `NEGATIVE_MODEL_CONFIG` : V9 Phase 2 V7 à 0,50 ; V11 human-aligned avec thresholds v2. Chaque version utilise les mêmes textes, 3 répétitions, concurrence totale 8, requested model jev-latest. Google ratings et préannotations ne sont jamais envoyées à Jev.

Le worker serveur reprend les tâches pending après fermeture PWA. Une réponse payante non confirmée devient unavailable et ne se rejoue pas automatiquement. Il ne contient aucun appel Sol/OpenAI ou Apify. Les modèles servis, tokens, coûts estimés et durées sont conservés. Les résultats sont publiés seulement après terminaison des tâches puis immuables. Les scores comparent les mêmes avis disponibles pour les deux versions ; la couverture partielle est affichée. Micro F1 exclut les true negatives ; macro F1 exige un support IA ≥ 3. Accord exact et stabilité sont séparés. Les faux positifs potentiels peuvent être positifs ou négatifs ; les critiques manquées concernent la polarité négative. Toutes ces mesures restent exploratoires face à une référence IA qui peut elle-même se tromper.

Après completion, **Avis à vérifier** réutilise ces réponses dans le parcours existant `jev-exploratory-review`. Il ne relance pas Jev. La liste présente texte anglais, note descriptive, IDs, probabilités, polarités et motifs (y compris désaccords avec la référence IA). L’utilisateur sélectionne les avis, donne un **GO**, exporte vers ChatGPT puis importe les nouvelles corrections. Celles-ci restent dans `analysis_jev_exploratory_corrections`, séparées du snapshot initial et des préannotations. V11 n’est pas recalibré automatiquement.

Le second dataset de 32 avis dans `analysis_v11_independent_holdout_sets/items` est seulement lu pour exclure toute intersection ; aucune ligne ni aucun hash n’y est changé. Il reste disponible pour une future évaluation exploratoire indépendante du premier jeu.
