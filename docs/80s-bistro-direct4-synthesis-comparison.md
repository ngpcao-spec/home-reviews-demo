## Exact future limits

- JEV: **0** new requests.
- Luna: **4** new grouped requests, **6** questions, one attempt each; no retry after dispatch, timeout or lost response.
- Sol: **1** request maximum, after the existing accepted-evidence and size gates.
- Apify: **0**.

A new, protocol-specific GO is mandatory. Preparing a protocol is not authorization. The old execution consent cannot be reused. The future delegated workflow uses the existing authenticated server RPCs; it compiles/tokenizes the final accepted request off the Edge critical path, seals it, then reserves once before dispatch. The receipt is saved before a separate validation wake. No correction call is allowed.

Free qualification uses the real immutable source, real saved Luna results, and explicitly synthetic new Luna/Sol responses with native provider network disabled. Deployed probes also use injected mocks and exit before reading supplier keys. They check the active routing, grouped requests, accepted-only packet, token certificate, receipt, validation and final save. They do **not** measure future semantic accuracy.

Because the comparative dossier adds previously unverified evidence, a future report difference cannot be attributed solely to the synthesis prompt. Qualitative assessment remains in the user's analysis chat.
