Limites : les tests offline vérifient instructions, payloads, calculs, sécurité et lifecycle ; ils ne prouvent pas la classification réelle du modèle. Le tarif/tokenisation avant lancement donne une estimation, pas une facture garantie. V11 n’est pas réévaluée ; les avis sources invalides sont exclus.
